# 观星塔

一个简约复古的私人记录网页，用来整理日常心情、角色感想、关系图与图像收藏。

## 使用

下载本仓库后，在浏览器打开 `index.html`。网站发布时使用 `dist` 文件夹；其中的 `index.html` 是在线版入口，包含首次使用说明。

无需安装依赖，也不调用 AI 服务。

## 功能

- 自由发帖、图片、标签、收藏、草稿与搜索
- 档案及所属角色、头像裁切、多个角色关联
- 角色贴膜站与家产小屋
- 可拖动、有方向与自定义颜色的角色关系图，分组及档案筛选
- 拾星馆相册及正文插图
- 壁纸、透明度与可记忆的折叠目录
- 完整 JSON 备份导出与导入

## 数据保存

内容保存在当前设备、当前浏览器的网站存储中，不上传到 GitHub，也没有账号或跨设备同步。同一浏览器配置访问同一网址时会共用内容。清除浏览器数据可能丢失记录，请定期导出备份。

从本机文件迁移到在线网址，或更换网址时，请先导出再导入完整备份。

## 文件

- `index.html`、`style.css`：页面与样式
- `app.js`：基础记录与存储
- `extras.js`：壁纸与关系图
- `studio.js`：图像馆、头像裁切与整理
- `garden.js`：角色贴膜站与折叠目录
- `dist/`：可直接用于静态托管的发布文件

修改根目录源文件后，应将对应文件同步到 `dist/`，再发布网站。

## 六套主题

顶部主题按钮可选择初始、科技、星空、森林、甜美与 ins 风格。主题保存在本机档案设置中，并随完整备份导出。`themes.js` 与 `themes.css` 管理主题行为与样式；修改后也需同步到 `dist/`。
